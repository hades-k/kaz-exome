```python
input_file = 'id2pop.txt'
output_file = 'id2pop_fix.txt'

with open(input_file, 'r', encoding='utf-8') as f:
    lines = f.readlines()

fixed_lines = [
    line.replace(" Chinese", "_Chinese").replace(" Vietnamese", "_Vietnamese")
    for line in lines
]
with open(output_file, 'w', encoding='utf-8') as f:
    f.writelines(fixed_lines)
```

## Pairwise Fst 

Using VCFtools to calculate pairwise fst between each possible pairs. This requires a vcf file and a separate files with sample names from each population.

Recoding

```bash 
plink --bfile merged_large_pruned --recode vcf-iid --out merged_large_pruned
```

Using the .ind file that was created for AncestryPainter

```bash
awk '{filename = $1".txt"; print $2 >> filename}' merged_large_pruned.ind
```

Setting up a bash script that uses this function  

```bash
vcftools --vcf "$VCF" \
            --weir-fst-pop "${POP_DIR}/${POP1}.txt" \
            --weir-fst-pop "${POP_DIR}/${POP2}.txt" \
            --out "${OUT_DIR}/fst_${POP1}_${POP2}"
```

## LSBL calculations

To calculate LSBL we used the following formula: $LSBL_A = \frac{F_{ST}^{A,B} + F_{ST}^{A,C} - F_{ST}^{B,C}}{2}$

Given that LSBL can oly be calulated for triads, first triad analyzed was Kazakh, British, Han Chinese, as British and Han Chinese provided the lowest Fst values when compared to other populations in their supergroup. 

In this plot, the dashed line represents the 99th percentile

```R
library(ggplot2)
library(dplyr)
library(tidyr)

lsbl_df <- read.csv("lsbl_kaz_brit_han.csv")

lsbl_df <- lsbl_df %>% arrange(CHROM, POS)

lsbl_df <- lsbl_df %>%
  group_by(CHROM) %>%
  mutate(chr_len = max(POS)) %>%
  ungroup() %>%
  mutate(tot = cumsum(as.numeric(lag(chr_len, default = 0)))) %>%
  mutate(BPcum = POS + tot)

axis_df <- lsbl_df %>%
  group_by(CHROM) %>%
  summarize(center = (min(BPcum) + max(BPcum)) / 2)

lsbl_df <- lsbl_df %>% filter(!is.na(LSBL), !is.na(POS))

ggplot(lsbl_df, aes(x = BPcum, y = LSBL)) +
  geom_point(aes(color = as.factor(CHROM)), alpha = 0.75, size = 1.2) +
  scale_color_manual(values = rep(c("steelblue", "skyblue"), length.out = length(unique(lsbl_df$CHROM)))) +
  scale_x_continuous(label = axis_df$CHROM, breaks = axis_df$center) +
  geom_hline(yintercept = quantile(lsbl_df$LSBL, 0.99), linetype = "dashed", color = "darkgray") +
  labs(x = "Chromosome", y = "LSBL (Kazakh)", title = "Genome-wide LSBL Plot") +
  theme_minimal() +
  theme(legend.position = "none",
        panel.grid.major.x = element_blank(),
        panel.grid.minor.x = element_blank())

ggsave("brit_han.png", width = 12, height = 5, dpi = 300)
```
